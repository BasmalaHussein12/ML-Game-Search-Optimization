# ML-Game-Search-Optimization

## Overview

An independent research project exploring the intersection of Machine Learning and classical adversarial search algorithms.

The project aims to investigate whether Machine Learning techniques can improve move ordering in Alpha-Beta search, with Connect Four as the initial experimental environment.

## Research Focus

- Minimax and Alpha-Beta Pruning
- Classical Move Ordering Heuristics
- Machine Learning-Guided Search
- Hybrid AI Approaches

## Current Stage

**Literature Review & Research Exploration**

Currently exploring existing research to understand the problem, identify research opportunities, and define a feasible experimental methodology.

## Research Status

This project is in its early research and exploration phase. The research questions, methodology, and implementation will be refined based on the literature review.
